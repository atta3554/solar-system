# Solar System

An interactive 3D Solar System built with **Three.js**.
This project renders the Sun, planets, selected moons, and a space
environment with orbit-style motion and camera controls.

## Features

- 3D rendering with Three.js
- Interactive camera controls using OrbitControls
- Textured planets
- Animated orbital motion
- Moons orbiting planets
- Space background (skybox)

## Tech Stack

- Three.js
- Vite
- JavaScript
- HTML / CSS

## Installation

```bash
git clone https://github.com/atta3554/solar-system.git
cd solar-system
npm install
npm run dev
```
